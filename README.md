AdsMarket is a premium SaaS platform designed to bridge the gap between complex data and actionable advertising campaigns. By leveraging **Claude 3.5 Sonnet** and **GPT-4o-mini**, AdsMarket automates the entire workflow from keyword research to high-converting SEO content and Google Ads structures.

---

## ✨ Key Features

- **🔍 AI Keyword Research:** Deep-dive into market intent with automated clustering and volume analysis.
- **✍️ AI SEO Content Creator:** Generate fully optimized blog posts, meta titles, and descriptions in seconds.
- **📊 ROI Projection Engine:** Real-time performance monitoring and future profit forecasting via Google Ads API.
- **🚀 One-Click Campaign structure:** Auto-generate 15 headlines and 4 descriptions based on Google's best practices.
- **💎 Premium UX:** High-end dashboard featuring glassmorphism, 3D interactions, and real-time animations.

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3 (Premium Effects), JavaScript (Canvas Particles, Intersection Observer)
- **Backend:** PHP 8.1 / FastAPI (Router Logic)
- **AI Models:** Claude 3.5 Sonnet, GPT-4o-mini, text-embedding-3-small
- **Database:** PostgreSQL / MySQL
- **Integrations:** Google Ads API, Stripe, SMTP

---

## 🚀 Getting Started

### Prerequisites
- PHP 8.1 or higher
- MySQL Database
- Google Ads API Developer Token

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/oktayhaktan0/AdsMarket.git
   ```
2. Configure your environment:
   - Copy `api/config.sample.php` to `api/config.php`
   - Add your API keys and Database credentials.
3. Import the database schema (see `api/setup.php` for reference).
4. Launch your local server.
